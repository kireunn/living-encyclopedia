# The Living Encyclopedia

An interactive web encyclopedia for children aged 9–13, built for Erik Stybaev's diploma project (Communication and Media, University of Central Asia).

Each chapter is one scrolling page with real photos, video, live 3D models and small activities.

## What is here

| Path | What it is |
|---|---|
| `index.html` | Home page with the three chapters |
| `kity.html` | Chapter 1: Whales, a dive to 4,000 m |
| `kosmos.html` | Chapter 2: Space, from Earth's core to Pluto |
| `futbol.html` | Chapter 3: Football, one 90-minute match |
| `kity-static.html` | Static version of the whales chapter, used as the control in the study |
| `presentation/` | Diploma presentation (10 slides). Arrow keys to move, N for speaker notes |
| `presentation/offline.html` | The same presentation as one file that works without internet |

## Research

How does an animated, interactive web encyclopedia page affect knowledge retention and engagement among children aged 10–12 in Bishkek, compared to a static page with the same content?
